# Skills directory research and submission tracker

Checked 2026-11-23–24 (Asia/Shanghai). This expands the initial four-directory submission batch. Google was searched for `skill market` (two result pages), `agent skills directory "submit"`, and related English/Chinese queries. Each link below is a primary directory or its official submission/contribution route. This is a broad working inventory, not a claim that every directory on the internet has been found.

This inventory contains **42 directory/channel entries**. **12 have successful submission or listing evidence**: one published listing, ten review/indexing submissions, and one request-intake acknowledgment. Only a receipt or a verified public listing counts as a successful submission. A discovered website, login screen, crawler policy, failed form, or paid offer does not. Skill.Fish and MCP Market share a queue and are counted once. Names such as Skill Market, Open Skill Market, SkillsMarket and SkillHub refer to different operators unless explicitly grouped below.
